# My Cypress Automation

This project uses Cypress to perform automated tests for a login feature and a user update feature.
Cypress is a JavaScript-based end-to-end testing framework that allows developers to write execute tests in a real browser.

## Installation

```bash
npm install

```
>**NOTE**
>
>It is necessary to have **node** installed

## Running
``` bash
# You open the Cypress UI
npx cypress open

# Run the automation by command line
npx cypress run

```
